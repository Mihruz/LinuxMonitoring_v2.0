# LinuxMonitoring v2.0

Этот проект направлен на изучение мониторинга систем Linux с использованием таких инструментов, как GoAccess, Prometheus и Grafana.
В нем я генерировал файлы и логи, анализировал их, а также настраивал мониторинг для отслеживания состояния системы в реальном времени.
Ниже представлено краткое описание задач.

## Задачи
### Часть 1. Генератор файлов
Напишите скрипт, который создает папки и файлы с заданными параметрами (имена, размеры, количество).
Убедитесь, что скрипт останавливается, если остается менее 1 ГБ свободного места.
### Часть 2. Засорение файловой системы
Создайте скрипт для генерации большого количества файлов и папок в случайных местах файловой системы.
Логируйте все созданные файлы и время выполнения.
### Часть 3. Очистка файловой системы
Напишите скрипт для удаления файлов и папок тремя способами:
По лог-файлу.
По дате создания.
По маске имени.
### Часть 4. Генератор логов
Создайте скрипт для генерации файлов логов nginx в формате combined.
Каждый лог должен содержать случайные данные (IP, коды ответа, методы, даты, URL, агенты).
### Часть 5. Мониторинг
Разработайте скрипт для анализа логов с помощью awk.
Реализуйте вывод записей по различным критериям (коды ответа, уникальные IP, ошибочные запросы).
### Часть 6. GoAccess
Используйте GoAccess для анализа логов и отображения результатов в веб-интерфейсе.
### Часть 7. Prometheus и Grafana
Установите и настройте Prometheus и Grafana.
Добавьте метрики (ЦПУ, память, диск) на дашборд Grafana.
Проведите тесты нагрузки с помощью утилиты stress.
### Часть 8. Готовый дашборд
Установите готовый дашборд Node Exporter Quickstart and Dashboard .
Проведите тесты нагрузки сети с помощью iperf3 .
### Часть 9. Дополнительно. Свой node_exporter
Напишите скрипт или программу для сбора метрик системы (ЦПУ, память, диск).
Настройте Prometheus для сбора данных с созданной HTML-страницы.
